## Interactive demos

- **CIA Triad Scenario Analyzer** — classify attacks by which property they violate
- **Password Strength Meter** — real-time entropy analysis with crack-time estimates
- **Caesar Cipher** — live encrypt/decrypt with brute-force all 25 shifts
- **Packet Builder** — TCP/IP stack visualizer with clickable field explanations
- **Network Port Scanner** — simulated Nmap scan across a subnet
- **SQL Injection Lab** — vulnerable login form with injection payload sandbox
- **Malware String Analyzer** — static analysis of suspicious binary strings
